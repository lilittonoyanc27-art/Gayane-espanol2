# GAYANE — AVENTURA EN EL AEROPUERTO ✈️

Браузерная игра-симулятор для изучения испанского языка: Гаяне путешествует из Еревана в Мадрид.
Весь испанский текст кликабелен — по нажатию появляется армянский перевод (повторное нажатие скрывает его).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production-сборка в dist/
npm run preview    # просмотр сборки
npm run check-mazes  # проверка проходимости всех лабиринтов
```

Публикация: `netlify.toml` и `vercel.json` уже настроены (build: `npm run build`, папка `dist`).

## Что есть в игре

| # | Миссия | Что делает игрок |
|---|---|---|
| 1 | Prepara tu maleta | Интерактивная комната: перетаскивание вещей в чемодан/рюкзак по командам мамы, лимит веса, спрятанные предметы (ящик, подушка, шкаф, кот под кроватью), смена одежды в шкафу |
| 2 | Un taxi al aeropuerto | Диалог с таксистом |
| 3 | Explora el aeropuerto | Большой зал (2 этажа, эскалатор, лифт), табло вылетов, план терминала, сотрудник информации, пассажиры |
| 4 | Facturación | 8 стоек, нужно найти свою; диалог с ветвлениями (окно/проход) → посадочный талон |
| 5 | Control de seguridad | Выполнение испанских команд сотрудника: лоток, электроника, рамка (B1 — сработавшая рамка) |
| 6 | Control de pasaportes | Диалог у будки |
| 7 | El laberinto | 6 лабиринтов: лифты, эскалаторы, закрытые двери с загадкой, тайный проход, подсказки сотрудников, смена выхода; таймер можно отключить |
| 8 | Tiendas y cafetería | Кафе, duty free, сувенирный магазин: корзина, заказ фразой, оплата монетами, цены словами |
| 9 | Embarque | Табло у выхода (B1 — задержка и смена выхода), агент, телетрап, стюардесса, поиск места в салоне |
| 10 | La azafata y los pasajeros | 23 ситуации в самолёте |
| 11 | Pilota tu avión | Аркада: 3 уровня, звёзды, кольца, испанские команды |
| 12 | Llegada a Madrid | Паспортный контроль и таможня |
| 13 | ¿Dónde está mi maleta? | Багажная лента с описаниями возрастающей сложности + «потерянный багаж» |
| 14 | Una aventura en Madrid | Город: спросить дорогу, такси или метро (билет), отель → паспорт путешественницы |

**Режимы ответа в диалогах:** выбор, сборка фразы из слов, ввод текста (с допуском опечаток и ключевыми словами),
голос (Web Speech API, если браузер поддерживает), ролевая игра без подсказок. Реплики и варианты ответов
выбираются случайно, неверные ответы вызывают естественную реакцию персонажа.

**Уровни:** A1 Principiante · A2 Viajera · B1 Exploradora (B1 добавляет задержку рейса, смену выхода, потерянный багаж, вопросы без цифр).

**Управление:** WASD/стрелки — ходьба, Shift — бег, E/пробел — действие. На телефоне — джойстик и кнопка действия.

**Сохранение:** localStorage — миссии, очки, монеты, слова (раздел «Բառարան»), достижения, лабиринты, рекорды.

Озвучка — встроенный в браузер синтез речи (es-ES), без платных API.
